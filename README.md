
# Web Traffic Analytics

## Objective
To analyze website traffic and understand visitor behavior.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Website page views analysis
- Session duration analysis
- Traffic source analysis
- Device usage analysis
- User journey analysis
- Website drop-off analysis
- Conversion rate calculation

## Outcome
Identified website visitor behavior patterns and suggested improvements to increase user engagement and conversions.
